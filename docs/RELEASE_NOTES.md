# Release notes

This release organizes the existing FleetIO browser prototype for reproducible builds, packaging and redeployment through its existing GitHub/Vercel project.

- Documented locked dependency installation, Node 22.12+ setup, lint, simulation/presentation checks, production build and build verification.
- Documented the static release ZIP and manifest separately from editable Git source.
- Added a walkthrough for the fourteen scenario choices, manual recovery controls, ten home docks, two chargers, search and reduced-motion preferences.
- Recorded simulation, asset-license and rendering limitations without asserting physical safety or a frame-rate guarantee.

The release retains the browser simulation and its 3D warehouse demonstration. These notes describe the cleanup release; they do not assert that validation passed or that the production alias has advanced. Record the exact source revision and actual command, browser and deployment results in release evidence before reporting completion.
